The pipeline

1ComplaintText, product and age, cleaned up
2Safety rules C1 and C2Fixed rules, typo-tolerant, never trained
3Sentence classifierEach sentence: a symptom, or none
4Fixed rule orderC1, then C4 or C6, C3, C5, then a single symptom. Escalation comes from C1 and C2 only
5AnswerFive fields and one reason

The model never sets the escalation flag. If the model fails to load or throws, the safety rules still answer.
